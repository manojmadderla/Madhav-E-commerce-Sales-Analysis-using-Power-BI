# 📊 E-Commerce Sales Analysis Dashboard (Power BI)

## 📌 Overview

This project presents an interactive **E-Commerce Sales Analysis Dashboard** built using Power BI to analyze sales performance, profit trends, and customer purchasing behavior. The dashboard helps businesses track key metrics and make data-driven decisions to improve profitability and operations.

---

## 🎯 Objectives

* Analyze sales and profit performance across different states
* Understand category-wise sales and quantity distribution
* Track monthly profit trends
* Identify high-performing regions and product categories

---

## 📂 Dataset

The dataset used includes the following fields:

* Order ID
* State
* Category (Clothing, Electronics, etc.)
* Quantity
* Sales Amount
* Profit
* Order Date (Month/Year)

---

## 📈 Dashboard Features

### 🔹 1. Sales by State

* Bar chart showing **Sum of Amount by State**
* Helps identify top-performing regions (e.g., Maharashtra, Madhya Pradesh)

### 🔹 2. Quantity by Category

* Donut chart displaying distribution of quantity sold across categories:

  * Clothing
  * Electronics
  * Other categories

### 🔹 3. Profit by Month

* Bar/column chart showing **monthly profit trends**
* Helps identify profitable and loss-making months

### 🔹 4. Key Metrics Insights

* Highlights overall sales performance
* Enables quick comparison across regions and categories

---

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard creation and visualization
* **Excel / CSV Dataset** – Data source
* **DAX (Data Analysis Expressions)** – Measures and calculations

---

## 📊 Key Insights

* Certain states contribute significantly to overall revenue
* Clothing and Electronics dominate sales volume
* Profit trends fluctuate monthly, indicating seasonal patterns
* Some months may show losses, requiring strategic planning
